## Sobre o projeto

Projeto focado em visualização de dados utilizando a biblioteca **Matplotlib**, desenvolvido como parte da formação em Data Science da Alura. O objetivo é explorar as funcionalidades dessa poderosa biblioteca para criar gráficos estáticos, personalizados e informativos que facilitem a interpretação de dados e a comunicação de insights.

---

## Aprendizagens

- **Fundamentos do Matplotlib**: Como criar figuras, eixos e personalizar gráficos básicos (linhas, barras, scatter plots).
- **Gráficos avançados**: Construção de subplots, gráficos de área, histogramas e boxplots para análise multivariada.
- **Customização visual**: Ajuste de cores, marcadores, legendas, títulos e labels para melhorar a clareza e o apelo visual.
- **Anotações e elementos textuais**: Adição de textos, setas e anotações para destacar informações relevantes nos gráficos.
- **Salvando visualizações**: Exportação de gráficos em formatos como PNG, PDF e SVG para uso em relatórios e apresentações.

## Tecnologias utilizadas

- [Google Colaboratory](https://colab.research.google.com/): Ambiente de notebook interativo baseado na nuvem.
- [Python](https://docs.python.org/3/): Linguagem de programação.
- [Matplotlib](https://matplotlib.org/): Biblioteca principal para criação de visualizações estáticas e personalizáveis.
- [NumPy](https://numpy.org/): Biblioteca para computação numérica, usada para gerar dados de exemplo.
- [Pandas](https://pandas.pydata.org/): Utilizada para manipulação básica de dados quando necessário.
