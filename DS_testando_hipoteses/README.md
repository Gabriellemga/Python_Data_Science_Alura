## Sobre o projeto

Projeto focado na aplicação de **testes de hipóteses estatísticos** em diferentes cenários de dados, desenvolvido como parte da formação em Data Science da Alura. O objetivo é explorar métodos paramétricos e não paramétricos para validar suposições, comparar grupos e extrair conclusões confiáveis a partir de evidências estatísticas.

---

## Aprendizagens

- **Testes para uma amostra**: Aplicação de testes como t-test e Wilcoxon para comparar a média ou mediana de uma amostra com um valor de referência.
- **Testes para duas amostras**: Utilização de testes t independentes, Mann-Whitney e qui-quadrado para comparar grupos independentes e pareados.
- **Testes não paramétricos**: Implementação de alternativas não paramétricas quando os pressupostos de normalidade ou homogeneidade de variâncias não são atendidos.
- **Interpretação de resultados**: Análise de valores-p, intervalos de confiança e tamanho do efeito para tomar decisões baseadas em evidências.
- **Visualização de resultados**: Criação de gráficos que complementam a análise estatística, como boxplots e histogramas comparativos.
