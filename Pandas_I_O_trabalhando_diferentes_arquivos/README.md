## Sobre o projeto

Projeto de especialização em análise de dados desenvolvido durante a realização do curso [Pandas I/O: trabalhando com diferentes formatos de arquivos](https://www.alura.com.br/curso-online-pandas-io-trabalhando-diferentes-formatos-arquivos), ministrado pela instrutora [Valquíria Alencar ](https://www.linkedin.com/in/valquiria-alencar). A partir desse projeto, serão aprofundadas as técnicas de importação e exportação de arquivos utilizando-se a biblioteca Pandas.

## Aprendizagens

* O que são arquivos `CSV`, `XLSX`, `JSON`, `HTML` e `XML`;
* Como trabalhar com diferentes tipos de dados;
* Leitura de dados advindas do Google Planilhas;
* Reconhecimento e leitura de tabelas presentes em páginas da internet, sobretudo no formato HTML;
* Criação de um banco de dados local (SQLite);
* Escrita e leitura de dados em um banco de dados local;
* Realização de consultas SQL.


## Tecnologias utilizadas
- [Google Colaboratory](https://colab.research.google.com/): Ambiente de notebook interativo baseado na nuvem;
- [Python](https://docs.python.org/3/): Linguagem de programação;
- [Pandas](https://pandas.pydata.org/docs/): Biblioteca para manipulação e análise de dados;
- [SQLAlchemy](https://www.sqlalchemy.org/): biblioteca de mapeamento objeto-relacional SQL;
- [SQLite](https://www.sqlite.org/index.html): biblioteca que implementa um banco de dados SQL sem a necessidade de um servidor;
