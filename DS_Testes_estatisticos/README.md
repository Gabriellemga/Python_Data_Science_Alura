## Sobre o projeto
Projeto de análise de dados focado em testes estatísticos, desenvolvido para validar hipóteses e inferir insights sobre comportamentos de usuários em diferentes contextos.
O projeto utiliza bibliotecas como Pandas, SciPy e StatsModels para manipulação, processamento e aplicação de métodos estatísticos robustos.


## Aprendizagens

-Importação e tratamento de dados:
Carregamento e manipulação de dados estruturados a partir de arquivos CSV, com tratamento de valores missing e transformação de variáveis para adequação aos testes estatísticos.

-Análise exploratória:
Exploração inicial dos dados para identificar distribuições, tendências e possíveis viéses, utilizando técnicas de estatística descritiva e visualizações com Matplotlib e Seaborn.

-Aplicação de testes estatísticos:
Uso de testes paramétricos e não paramétricos (como teste t, ANOVA, Wilcoxon e Qui-quadrado) para validar hipóteses e comparar grupos, garantindo confiabilidade nas conclusões extraídas.

-Interpretação de resultados:
Análise crítica dos outputs estatísticos (valores-p, intervalos de confiança e efeitos práticos) para embasar decisões e comunicar findings de forma clara e assertiva.

## Ferramentas e técnicas
Linguagem: Python

Bibliotecas: Pandas, SciPy, StatsModels, Matplotlib, Seaborn

Métodos: Testes de hipóteses, visualização de dados, limpeza e preparação de datasets
