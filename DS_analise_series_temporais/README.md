## Sobre o projeto

Projeto de análise de dados focado em séries temporais, desenvolvido para estudar a contagem de bicicletas com base em dados de clima, estação do ano e outros fatores. O projeto utiliza a biblioteca **Pandas** para a manipulação e o processamento inicial dos dados.

-----

## Aprendizagens

  - **Importação de dados**: Como carregar dados de um arquivo CSV, utilizando a biblioteca **Pandas**.
  - **Tratamento de dados nulos**: Como identificar e tratar valores nulos nas colunas de usando o método `interpolate()` da biblioteca **Pandas**.
  - **Análise exploratória**: Verificação do formato dos dados, tipos de colunas e dados nulos com os métodos `shape`, `info()` e `isnull()`.
  - **Visualização de dados**: Como visualizar os dados, usando bibliotecas como `Matplotlib` e `Plotly`, para entender o comportamento das séries temporais.
