## Sobre o projeto

Projeto focado na **estilização avançada de tabelas** para visualização de dados, desenvolvido como parte da formação em Data Science da Alura. O objetivo é transformar tabelas simples em visualizações claras, informativas e visualmente atraentes, facilitando a interpretação de dados e a comunicação de insights.

---

## Aprendizagens

- **Formatação condicional**: Aplicação de cores e estilos baseados em valores das células para destacar padrões e outliers.
- **Estilos personalizados**: Criação de temas visuais consistentes usando paletas de cores e gradientes.
- **Barras de progresso em células**: Representação visual de valores numéricos através de barras horizontais dentro das tabelas.
- **Ícones e emojis**: Incorporação de elementos visuais para melhorar a comunicação e scanabilidade dos dados.
- **Funções de formatação**: Uso de funções personalizadas para aplicar estilos complexos baseados em múltiplas condições.
- **Exportação de tabelas estilizadas**: Salvamento de tabelas formatadas em HTML e Excel mantendo a estilização aplicada.
- **Acessibilidade**: Consideração de contrastes e padrões visuais para garantir legibilidade e inclusividade.

## Tecnologias utilizadas

 - [Google Colaboratory](https://colab.research.google.com/): Ambiente de notebook interativo baseado na nuvem.
- [Python](https://docs.python.org/3/): Linguagem de programação principal.
- [Pandas](https://pandas.pydata.org/): Manipulação de dados e estilização básica de DataFrames.
- [Pandas Styler](https://pandas.pydata.org/pandas-docs/stable/user_guide/style.html): Módulo principal para estilização avançada de tabelas.
- [NumPy](https://numpy.org/): Suporte para operações numéricas e cálculos.
- [Matplotlib](https://matplotlib.org/): Geração de paletas de cores customizadas.
- [Jinja2](https://jinja.palletsprojects.com/): Template engine para exportação em HTML.
